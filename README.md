## 📅 DAY 2 – OBJECT-ORIENTED PROGRAMMING

### Question 1 – Bank Account Management

**📝 Problem Statement:**

Create a class called `BankAccount` with the following:

**Instance Variables:**

- `accountHolder`
- `accountNumber`
- `balance`

**Requirements:**

1. A constructor to initialize all three variables.
2. A method `deposit(double amount)` to add money to the balance.
3. A method `withdraw(double amount)` to withdraw money if sufficient balance is available.
4. A method `displayDetails()` to display account information.

**In the main method:**

1. Create two `BankAccount` objects with different details.
2. Deposit money into both accounts.
3. Withdraw money from one account.
4. Display the updated details of both accounts.

### Question 3 – Shape Area Calculator: Abstract Class

**📝 Problem Statement:**

Create an abstract class called `Shape` containing only one abstract method:

```java
abstract double calculateArea();
```

Create three child classes:

1. **Circle** – Calculate area using π × radius × radius.
2. **Rectangle** – Calculate area using length × width.
3. **Triangle** – Calculate area using ½ × base × height.

**Requirements:**

1. Each child class must implement `calculateArea()`.
2. Create objects of all three classes.
3. Use a `Shape` reference to call `calculateArea()` for each object.
4. Display the calculated areas.

**Concepts Covered:** Abstract class, abstract method, inheritance, and runtime polymorphism.
